#  Лабораторная работа №3

**Тема:** основы JavaScript
**Задание:** реализовать набор функций в каркасе [js-tasks](https://github.com/teach-kirshdv/js-tasks).

 Код лежит в папке [`lab3`](lab3/), решения — в [`lab3/src/core.js`](lab3/src/core.js), тесты — в `lab3/src/core.spec.js`.

##  Как запустить

```bash
cd lab3
npm install   # установить mocha и prettier
npm test      # запустить тесты
```

##  Функции

| Функция | Что делает | Как реализовано |
|---|---|---|
| `isInteger(n)` | проверяет, что число целое | побитовый оператор `\|`, `===` |
| `even()` | массив чётных чисел от 2 до 20 | цикл `for`, `push` |
| `sumTo(n)` | сумма чисел от 1 до n | цикл `for`, оператор `+=` |
| `recSumTo(n)` | та же сумма, но рекурсией | рекурсия |
| `factorial(n)` | факториал n | цикл `for`, оператор `*=` |
| `isBinary(n)` | является ли n степенью двойки | побитовый оператор `&` |
| `fibonacci(n)` | n-е число Фибоначчи | цикл `for`, две переменные |
| `getOperationFn(initialValue, operatorFn)` | функция, накапливающая результат операции | замыкание |
| `sequence(start, step)` | генератор арифметической прогрессии | замыкание, параметры по умолчанию |
| `deepEqual(a, b)` | глубокое сравнение двух значений | рекурсия, `Object.keys`, `for...of`, `in`, NaN |

# Лабораторная работа №4

**Тема:** современный CSS и основы ООП в JavaScript.

В папке [lab4](lab4/) находится обновлённая версия сайта «Досуг» из ЛР № 2.

| Требование | Где посмотреть |
| --- | --- |
| Flexbox | На всех страницах. Шапка, меню и вводный блок. |
| Grid | На всех страницах. Основная область, общая сетка карточек и поля формы. |
| Цветовые переменные и БЭМ | [Таблица стилей](lab4/css/style.css), палитра в :root и классы блоков, элементов и модификаторов |
| CSS-анимация | Иллюстрация книг на странице «Чтение», ключевые кадры book-float |
| Форма | [План на вечер](lab4/plan.html), текст, список, дата и многострочная заметка |
| Класс и отправка формы | [EveningPlan](lab4/js/plan.js) создаёт экземпляр из заполненной формы и печатает данные в консоль. [Локальный сервер](lab4/server.js) принимает POST /plans и проверяет поля. |

## Запуск

Из корня репозитория:

~~~powershell
node lab4/server.js
~~~

Откройте http://127.0.0.1:8000/. Устанавливать пакеты не нужно.

Перейдите в «План на вечер», откройте консоль разработчика, укажите имя, занятие и дату, затем нажмите «Отправить план». Консоль покажет поля созданного объекта, а страница подтвердит приём после ответа сервера. Сервер проверяет данные в запросе без записи в базу.

**Учебные материалы:** методичка «Лабораторная работа № 4 v1.3». Лекция «5. Modern CSS», слайды 11–18 (Flexbox и Grid), 22–25 (CSS-переменные), 29–37 (БЭМ). Лекция «4. JavaScript», слайды 23–27 (функции и объекты).
