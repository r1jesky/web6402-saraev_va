#  Лабораторная работа №2

**Тема:** основы HTML и CSS
**Сайт:** «Досуг» — подсказывает, чем занять свободный вечер. Каждая страница — отдельный вид досуга.

 Код лежит в папке [`lab2`](lab2/). Чтобы посмотреть сайт, откройте [`lab2/index.html`](lab2/index.html) в браузере.

#  Лабораторная работа №3

**Тема:** основы JavaScript
**Задание:** реализовать набор функций в каркасе [js-tasks](https://github.com/teach-kirshdv/js-tasks).

 Код лежит в папке [`lab3`](lab3/), решения — в [`lab3/src/core.js`](lab3/src/core.js), тесты — в `lab3/src/core.spec.js`.

##  Как запустить

```bash
cd lab3
npm install   # установить mocha и prettier
npm test      # запустить тесты
```

##  Функции

| Функция | Что делает | Как реализовано |
|---|---|---|
| `isInteger(n)` | проверяет, что число целое | побитовый оператор `\|`, `===` |
| `even()` | массив чётных чисел от 2 до 20 | цикл `for`, `push` |
| `sumTo(n)` | сумма чисел от 1 до n | цикл `for`, оператор `+=` |
| `recSumTo(n)` | та же сумма, но рекурсией | рекурсия |
| `factorial(n)` | факториал n | цикл `for`, оператор `*=` |
| `isBinary(n)` | является ли n степенью двойки | побитовый оператор `&` |
| `fibonacci(n)` | n-е число Фибоначчи | цикл `for`, две переменные |
| `getOperationFn(initialValue, operatorFn)` | функция, накапливающая результат операции | замыкание |
| `sequence(start, step)` | генератор арифметической прогрессии | замыкание, параметры по умолчанию |
| `deepEqual(a, b)` | глубокое сравнение двух значений | рекурсия, `Object.keys`, `for...of`, `in`, NaN |
