#  Лабораторная работа №2

**Тема:** основы HTML и CSS
**Сайт:** «Досуг» — подсказывает, чем занять свободный вечер. Каждая страница — отдельный вид досуга.

 Код лежит в папке [`lab2`](lab2/). Чтобы посмотреть сайт, откройте [`lab2/index.html`](lab2/index.html) в браузере.

##  Страницы

| № | Страница | Файл | Что на ней |
|:---:|---|---|---|
| 1 |  Чтение | `index.html` | три философских течения (экзистенциализм, стоицизм, гедонизм) и по одной книге из каждого |
| 2 |  Спорт | `sport.html` | пять форматов (зал, волейбол, бассейн, кольцо, бег) и плюсы каждого |
| 3 |  Кино | `movies.html` | шесть фильмов под разное настроение |
| 4 |  Игры | `games.html` | CS2, Dota 2, Valorant, Apex, DOOM, Ведьмак 3, GTA V: суть и турниры |
| 5 |  Разложение | `scroll.html` | YouTube Shorts, Instagram Reels, TikTok |
